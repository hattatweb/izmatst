Anmelden

Mit deinem GitHub-Zugang kannst du Texte, Preise und Bilder ändern. Änderungen sind nach ca. 1–2 Minuten auf der Website sichtbar.

Wie bekomme ich einen Token?
  1. Bei GitHub anmelden → Einstellungen → Developer settings → Personal access tokens → Fine-grained tokens.
  2. „Generate new token“, Repository auswählen, Berechtigung Contents: Read and write.
  3. Token hier einfügen. Er wird nur in deinem Browser gespeichert und nie auf der Website veröffentlicht.
